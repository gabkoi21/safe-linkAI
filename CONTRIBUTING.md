# Contributing to SafeLink AI

Describe the problem and proposed behavior in an issue before starting a significant change. Never include credentials or private analysis submissions in issues, commits, or screenshots.

Follow the setup in [development.md](development.md). Keep changes focused and include relevant verification results in your pull request. Update the documentation when configuration or behavior changes.

For frontend changes, run `bun run build` from `frontend/`. For backend changes, use the checks described in [backend/README.md](backend/README.md).
